Comandos LARAVEL: 

php artisan serve -> Para ejecutar el proyecto

php artisan tinker -> Muy útil para encriptar constraseñas

composer install -> para instalar todas las dependencias

php artisan migrate para migrar la base de datos, ya que con el .env tiene acceso a ella.

php artisan key:generate -> Para crear la clave Base64 y se guarde en nuestro archivo .env

composer require laravel/breeze --dev ->  Este paquete proporciona una solución mínima y simple para la 						  autenticación de usuarios (login, registro, recuperación de contraseña, 					  etc.) en aplicaciones Laravel.

php artisan breeze:install -> Esto Instala las vistas y archivos necesarios para la autenticación,Genera los 				      controladores y rutas y Añade la funcionalidad de autenticación Auth::login() o 				      Auth::register().


php artisan make:model task -mcr -> Crea el Modelo, el controlador, y la migración.





//VUE.JS

npm install -> Para instalar todo lo necesario node_modules

npm run dev -> Esto construye los archivos finales del proyecto, en la carpeta public (Archivos de diseño).

Al ejecutar npm run dev, has iniciado el proceso de desarrollo en tu proyecto de Laravel utilizando Vite. Esto hace que el servidor de desarrollo se inicie, lo que te permite trabajar en los archivos de tu frontend (JavaScript, CSS, etc.) y ver los cambios en tiempo real sin necesidad de recargar la página manualmente.
